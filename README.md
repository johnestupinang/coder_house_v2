# Simulador de notas académicas

Permite registrar alumnos con sus notas, calcular promedio y saber si aprobaron o reprobaron.


## Cómo ejecutarlo

1. Descargar/clonar el repositorio.
2. Abrir el archivo index.html en el navegador (doble clic o clic derecho y abrir con Live Server)
3. Abre la consola con F12 y ve a la pestaña **Console** para ver los console.log
4. REsponde los promp del menu para usare el simulador.

**No se necesita intalar nada**

## Que hace
Al cargar se crean tres alumnos de ehemplo y se muestran en la consola con su promedio.
